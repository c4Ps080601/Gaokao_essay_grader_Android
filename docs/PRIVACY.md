# 隐私与权限

- API Key 使用 AndroidKeyStore 加密，只在模型认证或主动点击“显示”时解密。普通设置和备份不返回明文；隐藏、切后台或离开配置面板后不再显示。
- 作文与照片的模型请求直接发送至使用者所配置的 HTTPS 服务商，没有项目自建中转服务。模型返回内容、保存的作文与结果在应用私有目录；系统备份关闭。
- 拍照委托系统相机，通过临时 URI 获取，编码输出不复制原始 EXIF。文件导出使用系统文件选择器和只读临时分享 URI，没有广泛存储或相机权限。
- 前台服务、dataSync、通知与有限时长唤醒锁用于已提交任务；通知不显示作文、用户名或 Key。没有开机自动批改或系统结束后自动收费恢复。
- 网络检查为主动触发的无认证 HEAD 请求，只检查服务商源站连通性，不含 Key 或作文，不调用模型。
- 用户名仅用于本机分组，不是安全登录机制。共享设备的使用者会共用模型配置，请勿把它当作账号隔离或云端身份验证。
- 请勿在 issue、日志、截图或提交中分享真实 Key、个人作文或签名文件。遇到问题仅提供经过脱敏的错误提示与复现步骤。

公开版本经过静态特征与人工检查，不构成对任意编码秘密的绝对保证；加入真实配置后需重新审查。
